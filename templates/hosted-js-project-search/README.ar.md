# مثال بحث المشروع — API 1.1

[English](README.md)

قالب hosted-js يبحث عن ملفات JavaScript وتطابقات TODO النصية في ملفات المشروع المحفوظة، بما فيها الملفات المغلقة، ويعرض النتائج في لوحة للقراءة فقط. لا يعمل تلقائيًا عند فتح الملف؛ شغّل الأمر المعلن.

يتطلب API 1.1 وصلاحية FILE_READ، وتستخدم UI_ACCESS لعرض اللوحة. استبدل الأيقونة المؤقتة assets/icon.svg وعدّل المعرّف والناشر والإصدار والترجمات وملف LICENSE قبل النشر.

```sh
rawanide-sdk validate .
rawanide-sdk audit . --repository
rawanide-sdk pack .
```

تُنشأ حزمة .r1 في مجلد المشروع افتراضيًا. راجع توثيق workspace-search في SDK لمعرفة الحدود وإحداثيات UTF-16 والإلغاء والنتائج الجزئية. افحص ok وcancelled وtruncated وskippedFiles. القالب لا يقرأ التعديلات غير المحفوظة، ولا ينفّذ نتائج البحث أو يعدّل الملفات أو يتصل بالشبكة.
