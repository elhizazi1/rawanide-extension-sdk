# npm distribution

Package: `@elhizazi1/extension-sdk` · SDK **1.1.0** · host API **1.1**.
Registry: `https://registry.npmjs.org/`.

## For extension developers

```sh
npm install --global @elhizazi1/extension-sdk@1.1.0 --registry=https://registry.npmjs.org/
rawanide-sdk help
```

The npm README includes English and Arabic documentation on the same page. The archive also includes `README.ar.md`. SDK users build and validate their own extensions; publishing the SDK itself is a maintainer operation.

## For SDK maintainers

Verify the package name, version, publication contents and npm registry before publishing. Source maintenance and tests require the full source checkout. Changes to source documentation do not modify files already embedded in a published package.
